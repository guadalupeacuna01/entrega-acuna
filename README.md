Blog: POR AUSTRALIA 🇦🇺
Este proyecto fue desarrollado como parte del curso de Desarrollo Web, de Coderhouse. La propuesta consistía en crear un sitio web aplicando los conocimientos adquiridos en HTML y CSS.  
Elegí realizar un blog dedicado a Australia, país en el que viví durante 4 años. En este espacio planeo compartir anécdotas personales, consejos útiles y recursos para quienes estén pensando en viajar, trabajar o estudiar allí.

Objetivo: El objetivo principal fue practicar el diseño y la maquetación de un sitio web responsive utilizando HTML5 y CSS3.

Tecnologías utilizadas: HTML5, CSS3, Flexbox y Grid Layout, Diseño responsive.

Estructuta del sitio:
El sitio está compuesto por las siguientes secciones:
- Inicio: presentación del blog y bienvenida, más últimos artículos publicados.
- Guia de mochilera: tips y recomendaciones para viajar por Australia.
- Blod de viaje: historias personales sobre mi viaje en Australia.
- Galería de fotos: sección exclusiva para mis fotos favoritas.
- Contactame: presentación sobre mi más formulario básico de contacto (estático).

Estoy aprendiendo del diseño, soy una apasionada de los viajes y la comunicación. Este blog es un espacio personal desde el cual comparto experiencias y aprendizajes. 

Gracias por visitar!

Blog: POR AUSTRALIA🇦🇺

This project was developed as part of the Web Development course at Coderhouse. The assignment consisted of building a website using the knowledge gained in HTML and CSS.
I chose to create a blog dedicated to Australia, a country where I lived for four years. In this space, I plan to share personal stories, helpful tips, and useful resources for those planning to travel, work, or study there.

Purpose: The main goal was to practice designing and building a responsive website using HTML5 and CSS3.

Technologies Used: HTML5, CSS3, Flexbox & Grid Layout, Responsive Design.

Site Structure: The website is divided into the following sections:

Home: Introduction to the blog and latest articles.
Backpacker Guide: Tips and recommendations for traveling across Australia.
Travel Blog: Personal stories from my time in Australia.
Photo Gallery: A dedicated section for my favorite travel pictures.
Contact: A short presentation about me and a basic (static) contact form.
About Me: I'm passionate about travel, design, and communication. I'm currently learning web design and this blog is a personal space where I share my experiences and what I’ve learned along the way.

Thanks for visiting!
